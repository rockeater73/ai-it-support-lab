# Printer Offline or Unable to Print

## Scope

Use this procedure when an employee cannot print or a configured printer appears offline.

## User-safe troubleshooting

1. Confirm that the correct printer is selected.
2. Ask whether other employees can print to the same printer.
3. Confirm that the printer is powered on and does not display an error.
4. Ask the employee to restart the application they are printing from.

## Technician actions

1. Verify that the workstation can communicate with the printer.
2. Check the Windows print queue for stuck jobs.
3. Verify the Print Spooler service status.
4. Confirm the correct printer driver and configuration are installed.

## Escalation

Escalate when:

- multiple employees cannot use the printer;
- the printer has a hardware error;
- network connectivity to the printer is unavailable;
- administrative changes outside Tier 1 permissions are required;
- Tier 1 troubleshooting does not resolve the issue.
