# Windows Computer Running Slowly

## Scope

Use this procedure when an employee reports that a Windows workstation is unusually slow or applications take significantly longer than normal to open.

## User-safe troubleshooting

1. Ask the employee to save their work and restart the computer.
2. Confirm when the performance problem started.
3. Ask whether the entire computer or only one application is slow.
4. Ask whether any error messages are displayed.

## Technician actions

1. Check CPU, memory, and disk utilization.
2. Check available disk space.
3. Review recently installed software or updates when relevant.
4. Review system and application logs for relevant errors.
5. Check for failed or pending operating system updates.

## Escalation

Escalate when:

- hardware failure is suspected;
- performance remains severely degraded after Tier 1 troubleshooting;
- administrative remediation outside Tier 1 permissions is required;
- multiple devices exhibit the same problem.
